# P0–P10 完整研究流程和审核门槛

| 阶段 | 核心任务 | 不合格案例 |
|---|---|---|
| P0 | 核验公司主体、市场、代码、报告期、研究问题 | 误用同名证券、旧行情 |
| P1 | 建立一手来源、二手资料和行业来源台账 | 无URL、时间、表格位置 |
| P2 | 历史3–5年财报、最新季度、公司分部数据 | 年报与季报口径混用 |
| P3 | 收入质量、其他收益、OCI、Non-GAAP、现金流 | 投资收益当主营收入 |
| P4 | 行业竞争、份额分母、客户/商户单位经济 | 支付前GMV与核销后GMV直接比较 |
| P5 | 宏观事实→业务驱动→现金流 | 把就业代理变量当失业统计 |
| P6 | 收入、价格、利润率、资本支出及三情景 | 凭空填一串固定增速 |
| P7 | FCFF/FCFE、分部DCF/SOTP、行业专用估值 | 现金、战略投资、SBC重复计价 |
| P8 | 逆DCF、敏感性、投资论点证伪 | 只给单点目标价 |
| P9 | 报告、图表、来源链接 | 图表无来源和统计范围 |
| P10 | 自动/人工QA、版本追踪 | 忽略硬性错误或数据缺口 |

## 来源等级

优先官方财报及附注、交易所和监管公告、权威统计原表；其次经明确识别的投行预测、新闻报道和第三方调研。逐项标注：

- `reported`：正式公司披露；
- `official-stat`：官方统计或政策；
- `consensus` 与 `broker`：市场一致预期/可核实的券商观点；
- `expert-estimate` / `analyst-estimate`：调研或研究者推断；
- `derived`：列出计算公式的推导值；
- `illustrative`：虚构演示数值。

发现口径冲突时停止合并数值，列出差异并分别引用。历史数值应保留原始币种、披露单位、期间、是否追溯重述。

## 假设审计

每个核心现金流假设需要有经营机制支撑：数量、客单价、佣金/广告变现、履约/人员成本、运转资本、资本开支。避免把同一居民消费风险同时反映在收入减少、利润率减少和WACC上，除非能够给出不重合的风险依据。

## 股权价值桥

企业价值到股权价值应处理：超额现金、净债务、经营必需现金、租赁负债、战略投资及税负、少数股权、可转债、优先股、SBC/回购与稀释股数。每一项只能计入一次。

## 终值与估值置信度

必须公开DCF终值现值占比、资本成本与长期g、稳态ROIC及再投资关系。长期现金流敏感时不得声称精确合理价；按 `screen-grade` 或 `not-decision-ready` 标注，并说明补齐哪项证据才能升级。

## 质量状态

- `decision-grade`：经过来源、模型及关键假设复核，但不意味着保证投资结果。
- `senior-review-ready`：材料可靠但尚有非关键审核事项。
- `screen-grade`：关键估值输入仍为区间估计。
- `not-decision-ready`：关键财务数据或模型一致性检查缺失/失败。
