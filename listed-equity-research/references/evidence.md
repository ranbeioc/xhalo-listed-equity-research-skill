# 证据管理、来源层级与逐项可审计引用

## 1. 数据层级

优先顺序：①交易所正式披露、经审计财报、SEC/监管公告、公司原始IR材料；②中央银行/统计局/财政部/行业监管官方统计；③同行公司原始披露；④可获得全文且可核查的券商研究；⑤独立产业/支付/行业数据库（完整说明抽样与口径）；⑥主流新闻转述；⑦专家访谈/传闻与非公开二手材料。**等级不是完全替代关系**：公司关于自身市占率的宣传属于当事人主张，需独立交叉验证。卖方一致预期需要统计时点、样本数量与指标定义。

## 2. 每项关键数据至少保留

- `source_id`：稳定不可复用（如 `S001`）；`url`：原始可打开页面；`publisher`；`publication_date`；`document_title`；`type`。
- `source_locator`：年报第N页/附注N/表格/段落；PDF页码和印刷页码若不同，应说明。
- `metric_id`：KPI唯一编号；`period` + `period_end`；`unit`（例如 RMB 亿元、HKD/股、同比%）；`value`；`basis`；`source_ids`。
- `derivation`：计算指标写出公式及组成 `metric_id`，并保证值可复算；跨币种转换需引用FX价格/日期及转换方法。
- `observed_date`：行情、汇率、份额、共识预测的抓取/测量日期；旧新闻不能当作最新价格。

主文引用推荐写 `[S001，2026中报第12页]`；文末真实超链接 `S001` 映射到URL。图表下方写来源ID、测量截止日和币种，不能只写“来源：网络”。

## 3. 信息状态

| label | 条件 | 用法 |
|---|---|---|
| `reported` | 公司财报/监管文件原文 | 可作基数，不自动代表“持续” |
| `official-stat` | 官方统计，需注明范围、口径 | 宏观背景 |
| `consensus` | 可核查样本数与截至时间的预期集合 | 只代表预期非未来事实 |
| `broker` | 具体研究机构/日期/模型推算 | 券商观点，非公司事实 |
| `expert-estimate` | 电话会/专家调研、抽样不明 | 低确信度旁证 |
| `derived` | 可追溯公式和源数据 | 数学推导 |
| `analyst-estimate` | 研究人员预测，需假设 | 情景估值 |
| `illustrative` | 虚构/演示输入 | 不可作投资事实 |
| `unknown` | 未找到可信披露 | 不填猜测值 |

## 4. 冲突处理

- 首先对齐：并表范围、会计准则、常量/现价、含税/不含税、GMV/GTV/已核销、日均/总量、月度/累计、季度/全年、股本类别。
- 不可对齐则并列显示双方来源和原因，不“强行调和”。
- 不能从 `GMV` 直接推出 `Revenue`，或从新媒体广告占比直接推出利润率。
- 第三方样本抽样不可自动代表全国市场。区分地区、城/农村、高线/低线城市。
- 股价、外汇、贴现率要写明时间和信息来源；不拿“盘中价”无日期地比较年末DCF。

## 5. 图表引用要求

每张图必须：可视化数据与`metrics.csv`或专业数据源一致；注明数量单位、数据口径、是否季节性调整/名义值、数据截止时点、`source_ids`；展示同比与绝对值要分轴或分图，不将百分比和人民币放同轴。预测用不同线型/底色并标记 `E`；不以插值伪造缺失月份。

## 6. 投行研究准则

可获取原始卖方报告时注明机构/分析师/发布日期/原币目标价/评级/盈利口径；只获取新闻转述时写“公开摘要/二手转引，未核对研报全文”。不能将不同日期的目标价直接平均成同口径一致预测；比较修正幅度须记录研报时间。
