# 宏观、居民消费、竞争格局及因果传导

## 核心规则：不要把宏观“列清单”当作估值

每一个宏观变量必须有业务链条：

`宏观观测 → 对客户/商户/资金/供应链影响 → 公司KPI → 毛利、费用、资本开支或融资 → 自由现金流`。

例：居民就业压力上升（官方/调查数据）→ 非必需消费意愿下降 → 高客单价服务交易AOV下降 → 广告收入/商户ROI可能下降；但低价外卖频次可能增加。这是**假设**，须用商家交易或公司数据验证。不要再额外用相同冲击无条件提高WACC。

## 建议检索维度（按相关性，不是所有公司都全用）

| 类别 | 指标 | 常见解释与反证 |
|---|---|---|
| 居民 | 实际可支配收入、人均消费、储蓄率、消费者信心 | 收入高于消费不等于绝对收入下降 |
| 就业 | 调查失业率、就业人数、行业招聘与工资、社会保险缴费 | 灵活就业≠失业；参保人数≠当月持续缴费人数；失业保险总支出≠失业人数 |
| 信贷 | 住户短贷/房贷净增、居民存款、提前还款、信用卡 | 净贷款下降可由需求弱、提前还贷、口径调整共同造成 |
| 房地产 | 房价、成交、库存、开发投资、按揭 | 资产负债表效应与新居消费通道分开 |
| 物价 | CPI、核心CPI、PPI、餐饮/服务分项与实际价格 | 名义与实际收入/交易分开；M2增长不自动等于CPI上涨 |
| 货币 | M0/M1/M2、社融结构、财政债券、收益率曲线 | 货币与信用结构，政府/私人扩张差；不能把低国债收益率直接换成海外投资者的Ke |
| 汇率 | USD/本币、EUR/本币、贸易加权NEER/REER | 美元欧元交叉汇率受第三货币影响；汇率水平不是央行意图的直接证据 |
| 贸易 | 出口订单、海关分品类、关税、外需/内需 | 行业传导由地区、客户与供给侧差异决定 |

## 竞争分析：必须同口径

1. 列出竞争地形（核心主业 / 互补业务 / 替代业务 / 潜在进入者）。
2. 对份额分母严格同口径：餐饮外卖 vs 即时零售；交易GTV vs 核销GTV；国内 vs 全球；平台净收入 vs 总额法销售额。
3. 拆 `数量×客单价×货币化率 - 补贴 - 变动履约成本`；增加商家获客成本与LTV/CAC。
4. 细分高利润业务的间接侵蚀，例如广告预算迁移可能先于核销GMV变更。
5. 最少提供一项**反证**：用户留存/市占率/运营效率是否显示平台仍有护城河？
6. 投行观点只有在给出报告日期、口径和具体假设时才进入共识对比。

## 样本代表性

不能由北上广某城区数据推导全国趋势；累计同比与单月同比区别；不能把限额以上企业与全行业数据直接相减，人口、门店样本、名义价调整需同口径。竞争第三方数据若采样误差不明，给范围不报个位小数。

## 避免重复定价

宏观与竞争可以**改变情景权重**，但现金流模型若已经对订单、AOV、广告率、补贴、资本投入下调，就要注明WACC中额外风险补偿的独立依据。采用冲击事件树可避免同一负面新闻在收入、经营利润、永续增长和折现率中重复计算。
