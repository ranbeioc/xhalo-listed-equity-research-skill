# 多行业估值路由：不可套用同一套“FCF利润率”

先判断**收入机制**、**资本结构**、**会计制度**及**核心资本约束**，再选择模型。以下仅为优先方法，不构成固定倍数建议。

| 公司类型 | 关键经营/财务驱动 | 主估值法 | 必查风险与口径 |
|---|---|---|---|
| 互联网平台/本地生活/电商 | GMV、take rate、1P与3P混合、商户广告、补贴/单、单位经济、网络效应 | 分部FCFF-DCF + SOTP + 同口径EV/EBIT/FCF | 1P收入按总额法、市场份额分母、SBC、关联投资、跨业务利润补贴 |
| SaaS/云/软件 | ARR、NRR、客户流失、CAC payback、毛利、FCF、RPO | DCF + EV/ARR/FCF成熟度分层 | SBC、收入递延、销售资本化、AI计算成本、未成熟利润率 |
| 制造业/工业/硬件 | 出货量、ASP、稼动率、毛利、单位成本、CAPEX、库存 | 周期归一FCFF + EV/EBITDA + ROIC | 产能过剩、固定成本杠杆、折旧、周期顶部不能用峰值PE |
| 消费/零售/餐饮 | 同店销售、客单、客流、开店/关店、毛利、渠道库存、租赁 | DCF + EV/EBIT/FCF，同店与门店数量分开 | 租赁负债、促销、加盟/直营、通胀名义增速 |
| 银行 | 净息差、贷款/存款、信用成本、不良/拨备、RWA、资本充足率 | P/B-ROE + 股利折现/DDM + 剩余收益RIM | 不用普通非金融FCFF；资本监管、信用风险、负债不是一般净债务 |
| 保险 | 保费、NBV、承保利润、综合成本率、内含价值EV、偿付能力 | P/EV、PVNBP、RIM/股息 | 利率久期、负债准备金、会计重估、资产负债匹配 |
| 券商/交易所 | AUM、交易额、费率、活跃账户、净资本与交易收入 | 正常化P/E、P/B-ROE、DDM | 交易活跃度周期性、自营收益、监管资本限制 |
| REIT/不动产 | NOI、入住率、租金续约、AFFO、杠杆、NAV | NAV + AFFO yield + DDM | 房产重估不等于现金收益、租金激励、再融资与租赁期限 |
| 能源/矿业 | 储量、产量、单位成本、回收率、油气矿价、税费、维持CAPEX | 商品情景NAV + DCF + EV/储量 | 资源寿命、弃置义务、价格远期曲线、矿权与合规 |
| 公共事业/基础设施 | 受监管资产RAB、准许回报、长期合同、负债、CAPEX | 监管回报DCF + DDM | 政策定价、收费上限、特许经营年限、利率敏感 |
| 医药创新/生物科技 | 分子管线、临床期、市场渗透、专利、许可分成、烧钱速度 | rNPV + SOTP + 资金需求/稀释 | 概率与时间双重调整、技术失败、增发融资与专利到期 |
| 多元控股/投资公司 | 核心运营、权益投资、金融资产、税负、债务、管理层资金分配 | SOTP + 控股折价 | 非经营资产重算、递延税、锁定期、折价叠加 |
| 周期/亏损公司 | 正常化盈利、现金跑道、融资与产能周期 | 周期归一DCF/EV指标、情景与融资稀释 | 负盈利不可用常规PE，未经融资补足不可给乐观每股目标价 |

## 行业方法选择（必须执行）

1. 若行业为**银行/保险**：优先监管资本与股东权益价值方法；不能把存款、保单负债当成普通“净债务”套非金融FCFF。
2. 若为**控股/多业务平台**：先识别分部财务公开程度，分别处理成熟盈利业务、资本密集业务、新项目、未并表资产；若利润拆分不可得，标成研究估算并做范围分析。
3. 若为**高杠杆/REIT/公用事业**：先拆经营租赁/融资债务及受监管现金流，再确定WACC/Ke和长期增速。
4. 若为**研发型亏损/资源有限寿命**：永续增长模型可能完全不适用，优先有限期rNPV、资产NAV或概率树。
5. 若为**高周期**：使用跨周期价格/产能与经营杠杆，不能把单一高点利润当永久基准。

## 研究输出层级

**通用强制指标**：至少 3 年关键财务 + 最新披露、份额/竞争或行业位置、资本结构与现金流、管理层资本配置、三情景、证据质量。

**分行业选配指标**：只加入对企业价值有解释力的KPI，不对银行强行画“毛利率”、不对生物医药未上市管线强行算传统P/E、不把保险保费等同实收现金流。
