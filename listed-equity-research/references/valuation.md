# DCF、SOTP、相对估值与反向DCF规范

## 1. FCFF定义与年度映射

成熟非金融企业常用：

`EBIT × (1 - marginal_cash_tax) + D&A - cash_CAPEX - ΔNWC - other_operating_investment = FCFF`

现金流从估值时点到年末折现；披露 `t`、折现惯例（年末/年中）、当年流量与估值时点。如果采用年度股权现金流FCFE，用 `Ke` 而不是 `WACC`。租赁口径必须与债务价值桥一致；税率区分名义、实际、税亏抵扣和一次性补税。

`WACC = We × Ke + Wd × Kd × (1 - T)`；`Ke = Rf + beta × ERP + 独立合理的国家/行业/规模风险溢价（避免重算）`。币种及名义/实际通胀必须一致；不应仅因为上市在香港就将人民币FCFF与美元Ke任意组合。对于复杂地域币种，用地域分部现金流折现或统一合理FX路径。

终值 `TV = FCF_last × (1+g)/(WACC-g)` 的使用条件：`WACC>g`，稳态增长不超出长期宏观可支持程度，并且**稳态ROIC及维持增长的再投资**支持该FCF。不能假设每年高速增长同时CAPEX/营运资本永久接近零。

## 2. SOTP不得重复计算

`Equity value = ∑Operating segments EV - corporate PV + excess cash + separable after-tax non-operating investments - interest debt - lease liabilities (if treated as debt) - minority interest - other senior claims + other net adjustments`

一项资产若通过分部DCF现金流贡献价值，不得再在“金融投资”项按账面价值添加；已合并子公司净资产与经营EV不能叠加；现金如果已用于并购或回购预测，不可再作为未使用期初超额现金加回。权益法企业可选择“盈利在DCF中”或“资产单独SOTP”，不能两者兼得。

非经营投资按**净可实现价值**核算：市值/公允价值 → 处置税 → 流动性/锁定折扣 → 潜在控股折价；债务需扣除对应可转债现金偿还或在稀释股本转股二选一。不凭所谓“价值回购”抵消现金支出。

## 3. SBC两条路径只能择一

路径A：把SBC视作非现金费用，在预测稀释股本和回购现金流时内生体现；终值反映长期净稀释（或股份回购现金需求）。路径B：将SBC视作经济成本从FCF中扣除，再按匹配口径处理股本。**禁止路径A和B全部重复计算**。透明披露“当前股份、完全稀释股份、净稀释率、每股价值”。

## 4. 相对估值（comps）

比较标的必须匹配：主业组合、成长、税率、地域、财报年份、账务总额/净额、租赁、现金/债务、会计调整、SBC政策。优先EV/EBIT、EV/FCF、P/E、P/B、AFFO等适用指标；未盈利/负自由现金流时不可假定倍数合理。历史均值与交易倍数不能无条件成为目标价。

**卖方分歧**：目标价按报告截至日、预测周期、估值基准与股本口径分组，展示高低及中位数；不可假设公开研报摘要可还原券商DCF。

## 5. 反向DCF与情景

- 从当前股价计算现有市值，反推当前EV，再求未来FCF margin/增长率/ROIC需达到何水平。
- Bear/Base/Bull须从订单量、AOV、产品组合、take rate、现金成本、资本投入、融资、税负自然推导，不只是调WACC。
- 不为不同负面消息机械叠加多重折扣；从“已计入现金流”与“尚需额外风险溢价”中识别重复因素。
- `Terminal PV / Operating EV`占比超过60%时需大字标记；超过75%时模型仍可用但结果通常仅作 `screen-grade` 并要求增加稳态ROIC、再投资及退出倍数交叉验证。
- 给 WACC×g 二维敏感性、FCF margin、竞争份额/成本、永续期贡献与净现金/投资资产桥。
- 报告目标价保留区间而非虚假精确小数；不同场景的数值必须与同一版本模型输出一致。

## 6. 股价与回报

当前股价需显示交易所、币种、日期时间、是否含盘中交易；核对红利/拆股/ADR换算/港币人民币FX。价格上涨空间应考虑估值日到实现年的时间、股息及投资风险，而不是把未来3年DCF值立即当成可兑现收益。
